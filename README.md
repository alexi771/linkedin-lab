# LinkedIn лаба

Материалы группы, которая два месяца вместе разбирается с LinkedIn: профиль, посты, нетворк.

## Уроки

- [Урок 1. Профиль: заголовок и «О себе»](урок-01-профиль.md) — план зума на 60 минут, шаги, шаблон результата и домашнее задание.

## Инструменты

- [linkedin-skills](https://github.com/sergebulaev/linkedin-skills) — набор из 12 скилов для Claude Code и Codex от Сергея Булаева, лицензия MIT. Подключён сюда как подмодуль в папке `linkedin-skills`.
  Каждый файл `SKILL.md` можно использовать как готовый промт: скопировать в Claude или ChatGPT и добавить свой текст. Для профиля это `skills/linkedin-profile-optimizer/SKILL.md`.

## Источники

- Tiger Sisters, «I Worked at LinkedIn. Here's How to Fix Your Profile»: https://www.youtube.com/watch?v=qCAHgny6a4Q

## Как сдавать результат

После урока каждый пишет в чат лабы сообщение с тегом урока, например `#профиль_01`. Шаблон есть в файле урока.
